# API para Prueba Técnica en Protección 🚀

Este proyecto es una **API RESTful** desarrollada como parte de la prueba técnica en **Protección** por **Juan Esteban Valdés Ospina**. 🧑‍💻

## Tecnologías Utilizadas 🛠️

- **Python 3.13** 🐍
- **FastAPI** ⚡
- **Uvicorn** 🚀
- **Docker** 🐋 (si aplica)
- **Render** 🌐 (para despliegue)
- **pytest** 🧪 (para pruebas)

## Endpoints 🌍

- **GET /**: Obtiene una presentación de la API. 📄
- **GET /docs**: Documentación Swagger interactiva. 📚

## URL de Producción 🌐

La API está desplegada en el siguiente enlace:
